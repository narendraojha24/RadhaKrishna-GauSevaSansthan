# 🐄 RadhaKrishna Gau Seva Sansthan

A spiritual and social welfare website dedicated to promoting the noble cause of Gau Seva (cow protection and care). This site serves as an online presence for Radha Krishna Gau Seva Sansthan, helping spread awareness, showcase activities, and collect donations to support the mission.

## 🌐 Live Site

[Visit Website](https://radha-krishna-gau-seva-sansthan.vercel.app)

---

## 📌 Features

- ✨ Clean and spiritual UI with a divine theme
- 📷 Photo gallery showcasing Gau Seva activities
- 📖 Sections about Sansthan’s mission, beliefs, and services
- 📱 Fully responsive design (mobile and desktop friendly)
- 💰 Donation call-to-action for interested devotees and supporters
- 🔗 Social media/contact links (if added)

---

## 🛠️ Tech Stack

- **Next.js**
- **tailwindCSS**
- **Responsive Web Design**
- **Vercel** for deployment
